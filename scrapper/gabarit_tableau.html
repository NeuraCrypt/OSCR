Comment un lien devient « code des auteurs »

Chaque lien est jugé sur la phrase et la section qui le portent : une section « Code availability », une ligne « This paper » du tableau des ressources, une référence signée par les auteurs de l'article. Un lien vers une boîte à outils publique (MNE, EEGLAB, FieldTrip…) ou vers un jeu de données est classé à part. La vérification peut corriger le texte : un dépôt de « données » qui contient des dizaines de scripts porte du code.

Ce qui n'est pas publié

Ni le texte des articles, ni leurs PDF : un lien DOI sortant, rien d'autre. Un dépôt sans licence reste un lien et un commit, jamais une copie.
